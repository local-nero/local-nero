I'm a **Brazilian game and software developer** who enjoys turning random ideas into actual projects.

I've worked on everything from game mods and tools to full-stack websites with authentication, databases, APIs, server-side game logic, and cloud-hosted infrastructure.

### Soggybet

Currently building **Soggybet**, a full-stack parody gambling website centered around fictional currency and collectible soggy cats.

What started as a small frontend experiment now includes:

- 👤 account registration & authentication
- ☁️ server-side cloud saves
- 🗄️ Cloudflare D1
- 🔐 server-authoritative economy
- 🎰 server-backed games
- 🐈 collectible Soggies
- 📦 inventories
- 💸 selling systems
- 🎁 daily rewards
- 🛟 anti-softlock protection
- 🔄 legacy save migration
- ⚡ ongoing performance optimization

> no real money. no crypto. no NFTs. just increasingly soggy cats.
